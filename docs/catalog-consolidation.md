# 数字工具目录合并

本轮只调整普通发现入口，不删除旧页面、不迁移收藏、不改已有求和或序列算法。新增页面沿用现有 MUI 与中英文工具语言包，不新增依赖。

| 普通目录入口 | 保留的兼容页面 | 说明 |
| --- | --- | --- |
| `number/statistics` 数据统计 | `number/sum` | 一列数字同时给出计数、总和、平均、中位数、最小和最大值；页面显式链接原求和的文本提取、自定义分隔与逐行累计 |
| `number/arithmetic-sequence` 等差序列 | `number/generate` | 两页均按首项、步长和项数生成序列；目录复用已有校验、示例和上限的等差序列页，不合并或改写旧算法 |

`tools` 保持完整路由库存；`catalogParent` 仅声明普通目录的合并目标。首页普通搜索、分类列表/计数和相关推荐使用独立入口，收藏继续按原 path 从完整库存查找。新增一个路由、合并两个旧展示入口，未筛选目录的独立入口净减一个；数量由实际目录数据计算，不写死减数。随机数、随机端口、换算、工程计算等专用工具不隐藏，不滥用延期工具说明。

数据统计每行只接受一个完整十进制数字，忽略空行，支持负数、小数和科学计数；遇坏行立即给原行号并清除结果，不跳过或从文本中提取数字。每次最多 10,000 个数字、200,000 字符，拒绝非有限值、下溢为零、不安全整数及超过 15 位有效数字的小数。采用补偿求和与一般浮点计算，安全整数完整显示，其余结果最多显示 15 位有效数字，不宣称财务或任意精度计算。

定向测试涵盖统计结果/严格输入/边界、目录与关键词、两类用户、旧计算合同、实际 Hero 收藏保留、结果失效/清空及剪贴板失败。运行测试时使用 `--dir src`，避免把 `.deployment/` 和 `docs/evidence/` 中旧源码副本计为新覆盖。浏览器实际渲染/交互与最终类型构建由集成负责人完成；本说明不代表已经提交、推送或上线。
