# 本地内嵌图标归属与许可

核对日期：2026-11-09。图标几何来自固定 Iconify 分发提交，按当前应用引用选择并重新打包为 JSON；没有改写原始路径数据。原作者署名依据同一固定提交的分发元数据。没有补造版权年份。

manifest.json 记录实际使用的集合、图标和别名、作者、许可及正文来源。original 表示额外取得的作者仓库许可快照，commit 是该许可文件的仓库版本；iconifyCommit 是几何源数据的版本，两者不可混称同一提交。standard 指向固定 SPDX 官方许可文本仓库的全文，标准模板中保留的占位符不代表原作者版权声明。

每套集合至少附权威标准许可全文和作者/作品来源；能够取得原始 LICENSE 的额外保留原件。CC BY / CC BY-SA 的归属随图标源数据和发行说明一起保留。许可链接仍保留供读者取得原文；本站运行时无需请求这些链接。

## 仅采用标准许可正文的条目

以下集合的完整许可由固定 Iconify 元数据声明，并附对应标准正文；没有把其他不相干软件包的 LICENSE 当作这些图标的原始版权文件：

- `hugeicons`：Hugeicons，MIT；作品/作者来源 https://icon-sets.iconify.design/icon-sets/hugeicons/；几何分发快照 https://raw.githubusercontent.com/iconify/icon-sets/3eb33380c7dbc256d098ada3f5a5863ec4b145dc/json/hugeicons.json。
- `lets-icons`：Leonid Tsvetkov，CC-BY-4.0；作品/作者来源 https://www.figma.com/community/file/886554014393250663；几何分发快照 https://raw.githubusercontent.com/iconify/icon-sets/3eb33380c7dbc256d098ada3f5a5863ec4b145dc/json/lets-icons.json。
- `solar`：480 Design，CC-BY-4.0；作品/作者来源 https://www.figma.com/community/file/1166831539721848736；几何分发快照 https://raw.githubusercontent.com/iconify/icon-sets/3eb33380c7dbc256d098ada3f5a5863ec4b145dc/json/solar.json。
- `streamline-plump`：Streamline，CC-BY-4.0；作品/作者来源 https://github.com/webalys-hq/streamline-vectors；几何分发快照 https://raw.githubusercontent.com/iconify/icon-sets/3eb33380c7dbc256d098ada3f5a5863ec4b145dc/json/streamline-plump.json。

Arcticons 的作者 README 明确区分应用程序 GPL-3.0 与所有图标 CC-BY-SA-4.0；归属材料采用其图标许可声明及 CC-BY-SA 标准全文，不将应用程序许可证误当图标许可。下载许可正文仅规范化行尾与尾空白，保留全部文字和已有版权年份。

`mdi-light:xml` 的固定 Iconify 元数据声明 OFL-1.1；另取得的作者仓库许可明确列图标为 Apache-2.0。两份材料与版本均保留，不悄悄改写元数据，也未分发字体二进制。
